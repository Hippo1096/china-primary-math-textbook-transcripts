### 主线证据链（8条）
1. **进位加·凑十法**：第1单元开篇即 9+4 凑十（盒内9个放1个凑满10格，"9凑10"，书页2）；后续按 8、7 加几与 6 及以内推进，凑十是全册进位加核心算法（书页2–21）。
2. **退位减·破十法**：与凑十对偶，十几减9/8/7等以"破十"（先减去10里的一部分再并回）为主线（书页约6起），凑十/破十构成20以内加减法运算一致性的第一站。
3. **认识20～99与位值**：第4单元以小棒捆（10根一捆）+计数器（十位/个位）双表征建立"几个十和几个一合起来"的位值概念，50有多大（综合与实践）以数与估衔接（书页42–56）。
4. **图形的初步认识（二）**：第2单元从立体图形描/印/拓出平面图形（长方形、正方形、三角形、圆），图形拼组（综合与实践，书页32–35）用图形拼图案，封面/封底积木情境即其表象（书页22–35）。
5. **数据分类（一）**：第3单元按不同标准对实物/图形分类整理，用象形统计表记录，为统计意识启蒙（书页36–41）。
6. **两位数加、减整十数和一位数**：第5单元口算主线（如 45+30、45+3、45−30、45−3），以位值"几十和几十加减、几个一和几个一加减"说理，是百以内笔算前的口算地基（书页57–70）。
7. **简单的数量关系（一）**：第6单元"比多少"三类问题（求相差数、求较大数、求较小数），以"同样多的部分+差"结构化表征（书页71–77）。

| 首单元 | 进位加法和退位减法（20以内，凑十/破十） | 20以内的退位减法（先减后加，破十/连减/想加算减） |
| 数的认识 | 认识20～99（不含100，位值双表征） | 100以内数的认识（含100，"10个十是1个百"） |
| 图形 | 图形的初步认识（二）：平面图形描拓+拼组综合实践 | 认识平面图形+用图形拼图案（无独立拼组单元） |
| 数据 | 数据分类（一）独立单元 | 无独立分类单元（分类启蒙在一年级上） |
| 加减口算 | 两位数加、减整十数和一位数独立单元（书页57–70） | 100以内口算加减法（整十数加减、两位数加减一位数/整十数，含小括号） |
| 笔算 | 本册不含竖式笔算 | 含100以内笔算加减法（进位/退位竖式） |
| 数量关系 | 简单的数量关系（一）独立单元（比多少三类） | 数量间的加减关系（比多少三类+多步问题，阅读理解/分析解答/回顾反思四步） |
| 观察物体 | 观察物体（一）独立单元 | 无独立单元（融入图形与生活情境） |
| 人民币 | 本册无（人教有"欢乐购物街"综合实践） | 欢乐购物街（认识元角分，综合与实践） |
| 综合与实践 | 图形的拼组、50有多大、数学连环画（3个） | 欢乐购物街等（含人民币主题） |
| 收束 | 期末复习（书页88起，无独立总复习单元标题） | 整理和复习+自我评价 |
| 后记 | 苏教版编修说明（2001年以来选用史、2022课标依据） | 人教版课程教材研究所编写说明（同为2022课标依据） |

**📌 编排要点**：苏教版把"位值—口算—数量关系—观察物体"各自独立成单元，结构颗粒度细；人教版同册覆盖到100以内数与笔算且含人民币，容量更大但单元更综合。两版共同主线均为"凑十/破十→位值→百以内加减→比多少"。
