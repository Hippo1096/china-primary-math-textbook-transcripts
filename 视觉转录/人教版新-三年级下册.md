### 1. 口算除法（续）

**例2（书页10-11）**：把69张彩色手工纸平均分给3人，每人分得多少张？**69÷3=23**。〔小棒分图〕想：**6个十÷3=2个十（60÷3=20）；9个一÷3=3个一（9÷3=3）；2个十+3个一=23（20+3=23）**。
📌口算拆分按计数单位分别除再相加——与乘法口算对称。
**例3（书页11）几百几十除以一位数**：口算120÷3。〔1张百格片+2条十位条 → 换成12条十位条分3组〕「1个百除以3，商不够1个百，可以把120看作12个十。」**120÷3=40，想：12个十÷3=4个十。**

## 单元三　长方形和正方形

### 多边形

**书页39 / PDF44**　单元三起页。主题图：教室与校园场景中的各种"面"。出示多边形概念：由线段围成的封闭图形叫作多边形。认一认：四边形、五边形、六边形等，按边数命名。例：三角形有3条边，四边形有4条边……（图示若干多边形请学生分类命名）

### 长方形和正方形的特点

**书页40 / PDF45**　例1：研究长方形和正方形的特点。用量一量、折一折、比一比的方法：
- 长方形：对边相等，四个角都是直角。长边叫**长**，短边叫**宽**。
- 正方形：四条边都相等，四个角都是直角。每条边叫**边长**。
- 联系与区别：正方形是特殊的长方形（四条边都相等的长方形）。

### 周长

**书页41 / PDF46**　例2：认识周长。描一描：树叶面、数学书封面、课桌面等物体表面或平面图形一周边线的长。定义框：**封闭图形一周的长度，是它的周长**。量一量、算一算：三角形三条边长度相加求周长（3+4+5=12厘米）；求给定图形的周长。

**书页42 / PDF47**　长方形、正方形的周长公式探究：长方形长6厘米、宽4厘米，求周长。方法一：6+4+6+4=20（厘米）；方法二：6×2+4×2=20（厘米）；方法三：**(6+4)×2=20（厘米）**。正方形边长5厘米：5×4=20（厘米）。归纳框：**长方形的周长=（长+宽）×2；正方形的周长=边长×4**。

### 例3：拼图与最短周长

**书页43 / PDF48**　例3：用16张边长1分米的正方形纸拼长方形，怎样拼周长最短？列表枚举：长16宽1→周长34分米；长8宽2→周长20分米；长4宽4（正方形）→周长16分米。发现：**拼成的长方形长与宽越接近，周长越短**。（散装的1平方分米正方形拼合时面积都是16平方分米，周长却不同）

### 练习八、九

**书页44-46 / PDF49-51**　练习八：①填空（多边形边数命名、周长概念）。②量一量、算出长方形和正方形的周长。③给黑板报花边求周长：黑板长4米、宽1米，花边至少多少米？④比一比：两个图形形状不同、周长是否相同（方格纸数边）。⑤思考题：一个长方形长16厘米、宽10厘米，剪去一个最大的正方形后，剩下图形的周长是多少？

**书页47-49 / PDF52-54**　练习九：①估一估、算一算校园中物体表面周长。②篮球场长28米、宽15米，小明沿球场边跑2圈共多少米。③用篱笆围长方形菜园（一面靠墙），求篱笆长度问题。④拼一拼：两个同样大的长方形拼成大长方形或正方形，比较不同拼法的周长。⑤实践活动：测量并记录家里物品表面的周长。

### 拼图游戏：四连方

**书页50-51 / PDF55-56**　"你知道吗/拼一拼"：用4个相同的正方形可以拼成不同的四连方（L形、T形、I形、田形、Z形等），画出各种拼法；比较相同面积下不同形状图形的周长，体会"面积相同，周长不一定相同"。

### 整理和复习（单元三）

**书页52 / PDF57**　知识结构整理：多边形→长方形和正方形的特点（对边/四边相等、四个直角）→周长的意义（封闭图形一周的长度）→周长公式（长方形（长+宽）×2、正方形边长×4）→解决实际问题（拼图最短周长策略）。**关键表述**：「周长是指封闭图形一周的长度，而面积是指物体表面或平面图形的大小」——周长是线的长度（一次度量），面积是面的大小（二次度量）。

## 单元四　图形的面积

### 面积的含义

**书页54 / PDF59**　单元四起页。主题图：打扫卫生——黑板面、墙面、地面等。观察：教室里哪些物体的面大、哪些面小？定义框：**物体表面或封闭图形的大小，叫作它们的面积**。比一比：两张纸谁大谁小（观察法、重叠法）；差异明显用观察，差异不明显（长方形与正方形卡片）用重叠法仍难判断→引出统一标准需要。

### 面积单位

**书页55 / PDF60**　数格子比较面积：同样大小的两张纸，用不同大小的方格去数，结果不一致→必须统一面积单位。介绍常用面积单位：
- **1平方厘米**：边长1厘米的正方形的面积（指甲盖大小）。
- **1平方分米**：边长1分米的正方形的面积（手掌大小）。
- **1平方米**：边长1米的正方形的面积（教室里4名学生手拉手围出的正方形大小）。
**关键表述**：「测量物体表面面积和测量物体长度一样，都是用标准单位去测量，看有多少个这样的标准单位」📌——面积的本质是面积单位的个数（计数单位的计数）。

**书页56-57 / PDF61-62**　做一做与练习十一：①用1平方厘米小正方形摆一摆、数一数给定图形的面积是几个1平方厘米。②找一找生活中面积约1平方厘米/1平方分米/1平方米的物体表面。③在方格纸上画出面积相同、形状不同的图形（等积变形）。

### 长方形、正方形面积的计算

**书页58 / PDF63**　例2：一个长方形长5厘米、宽3厘米，求面积。摆：用1平方厘米的正方形摆，每行摆5个，摆3行，共15个，面积15平方厘米。填表发现：**长方形的面积=长×宽**（每行个数×行数=长×宽）。正方形是长与宽相等的长方形，归纳框：**正方形的面积=边长×边长**。📌（面积=每行单位个数×行数——计数单位的行×列结构）

**书页59 / PDF64**　例3与做一做：利用公式解决实际问题——数学书封面长约26厘米、宽约18厘米，面积大约是多少平方厘米？（26×18=468平方厘米）一块正方形手帕边长2分米，面积是多少平方分米？（2×2=4平方分米）

### 面积单位间的进率

**书页60 / PDF65**　探究进率：1平方分米=多少平方厘米？边长1分米的正方形，用1平方厘米的小正方形摆：每行10个、摆10行，共100个→**1平方分米=100平方厘米**。同理，1米=10分米→**1平方米=100平方分米**。归纳框：相邻两个常用面积单位之间的进率是**100**。（对比长度单位进率10——一维与二维的差别）

**书页61 / PDF66**　换算方法：把高级单位换算成低级单位，乘进率100；低级单位换算高级单位，除以进率100。做一做：8平方分米=（　）平方厘米；5平方米=（　）平方分米；300平方厘米=（　）平方分米。

**书页62 / PDF67**　**关键证据页📌**：**1平方米=（　）平方分米**的完整推导——边长1米的正方形，可以看作边长10分米，10×10=100，所以1平方米=100平方分米。例：交通标志牌（正方形，边长8分米），它的面积是多少平方厘米？8×8=64平方分米，64平方分米=6400平方厘米。练习十二：单位换算综合练习；判断题（区分长度单位与面积单位的使用场景，如"课桌高70平方分米"错在哪里）。

**书页63 / PDF68**　练习十三：①填合适的单位：大树高16（　）；蜡笔长1（　）；字典厚5（　）；学校占地面积9000（　）。②比较大小：100平方米○10平方米；10平方分米○999平方厘米；400平方厘米○4平方分米；1000平方厘米○1平方米。③扫地机器人每分钟能打扫3平方米，房间长6米、宽4米，打扫这个房间需要几分钟？④街心花园长15米、宽6米的空地，用边长3分米的正方形地砖铺满，需要多少块地砖？⑤洒水车每分钟行驶200米、洒水宽度8米，5分钟能给多大面积的地面洒上水？⑥判断并说理由：(1)6平方米=60平方分米？(2)用8个相同的正方形拼成一个长方形只有一种拼法？(3)用8个1平方分米的正方形拼成的图形面积都是8平方分米？

**书页64 / PDF69**　练习十三续：⑦方格纸（每个□代表1平方厘米）画周长16厘米的长方形，能画几个？算出面积填表（示例①号：长7宽1、面积7、周长16），发现规律：**周长相等的长方形，面积不一定相等；长、宽越接近，面积越大**。⑧街心花园正方形花坛四周有1米宽的水泥路，水泥路总面积16平方米，花坛面积是多少平方米？**成长小档案**：「本单元结束了，你想说些什么？」学生范例：「我知道了1厘米和1平方厘米不一样。」——长度与面积是一维与二维两类不同的量。

### 你知道吗：《九章算术》

**书页65 / PDF70**　**你知道吗**栏目：我国古代数学名著《九章算术》方田章记载面积计算：「方田术曰：广从步数相乘得积步。」（方田：长方形田地；广=宽、从=长）——说明长方形面积公式在我国有两千多年的研究历史，体现数学文化。

**书页66 / PDF71**　整理和复习（单元四）：知识结构图——面积的意义（物体表面或封闭图形的大小）→面积单位（平方厘米、平方分米、平方米，相邻进率100）→面积公式（长方形=长×宽、正方形=边长×边长）→面积单位换算→解决实际问题（估测与测算）。**关键表述重申**：「测量物体表面面积和测量物体长度一样，都是用标准单位去测量，看有多少个这样的标准单位」📌（计数单位个数的度量观）；周长与面积的对比框：「周长是指封闭图形一周的长度，而面积是指物体表面或封闭图形的大小」。

## 年、月、日的秘密（综合与实践主题活动）

### 活动起页与年历中的秘密

**书页77 / PDF82**　主题活动起页：你关注过生活中这些现象吗？——一年四季（春夏秋冬四图）、月相变化图、昼夜交替图。**年、月、日是常用的时间单位**。

**书页78 / PDF83**　年历中的秘密——找一找：观察2023年和2024年的年历，发现年、月、日之间的秘密（一年中有12个月；有些月有31天，有些月有30天，2月……）。追问：为什么2023年2月有28天，2024年的2月有29天？**2月有29天的年份是闰年，有28天的是平年**。出示2015—2026年共12个2月年历卡片供观察，发现：**每4年有一个闰年\***。脚注：公历年份是4的倍数的一般是闰年，但公历年份是100的倍数时，必须是400的倍数才是闰年。如1900年不是闰年，2000年是闰年。

### 记一记、用一用

**书页79 / PDF84**　记一记：有31天的月份是**大月**，有30天的月份是**小月**。用**拳头记忆法**（凸起的地方每月是31天，凹下的地方每月是30天，2月除外）帮助记忆每月天数。用一用：①食品哪天到期？（面包生产日期2026.01.07、保质期3天；牛奶生产日期2026.02.06、保质期15天，算一算）你还关注过哪些物品的生产日期和保质期？②在空白月历上填出生日所在月份和今年这个月的各个日子，圈出有特别意义的日子。③某市小学放假时间：2026年1月24日（星期六）至3月1日（星期日）放寒假，2026年7月8日（星期三）至8月31日（星期一）放暑假——寒假、暑假分别是多少天？

### 作息时间表中的秘密与24时计时法

**书页80 / PDF85**　作息时间表中的秘密：小红和妈妈的周末作息时间表（上午/下午/晚上分栏，如小红7:15起床、12:00—2:30吃午饭午休等；妈妈表中出现14:30）。讨论：女儿和妈妈吃饭时间应该相同……；妈妈的时间表中14:30是怎么回事？**人们把地球自转一圈所需要的时间定为1天（日）**。

### 小讲堂：二十四节气与圭表测影
